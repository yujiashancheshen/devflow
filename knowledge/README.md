# 知识库

知识库只保存稳定背景、边界和工程规则。具体业务逻辑、接口字段、数据库结构和当前行为以代码为准。

| 分类 | 内容 | 主要使用阶段 |
|---|---|---|
| `business/` | 提交 `.md.example`；初始化后生成实际 `.md` | 需求澄清、概要设计、E2E |
| `architecture/` | 提交 `.md.example`；初始化后生成实际 `.md` | 概要设计、详细设计、E2E |
| `engineering/` | 后端、前端和测试通用能力 | 详细设计、编码、代码审查 |

判断标准：普通需求会频繁改变的内容不进入知识库；当知识与代码冲突时，以代码为准并更新知识。

`engineering/` 不包含业务属性，可以直接维护团队通用的后端、前端、SQL 和测试标准。
