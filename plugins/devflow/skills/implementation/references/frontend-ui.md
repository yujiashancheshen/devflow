# 前端 UI 实施

仅在当前范围包含 UI、页面状态或视觉来源时读取。

- 继承 `design.md` 已确认的页面落点、组件边界、复用决策和 UI 来源，不在实施阶段重新选型。
- 先使用确定性 fixture 或 API Mock 完成页面和状态，再接入真实请求、store、权限和业务副作用。
- 页面测试从真实页面入口触发，断言用户可观察结果，不绑定组件内部实现。
- 视觉验证优先使用仓库已有能力和设计中记录的工具、命令、视口与阈值；Skill 不固定依赖某个设计平台或视觉工具。
- 视觉产物写入 `docs/implementation/<仓库名>/visual/<页面>/`，不得写入业务仓库或 `codebase/`。
- 视觉工具不可用时如实记录限制，不得伪造评分或用肉眼结论覆盖失败结果。
- 设计与真实代码无法同时满足时暂停受影响页面并返回详细设计。
