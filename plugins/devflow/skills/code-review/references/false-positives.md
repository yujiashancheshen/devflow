# 误报控制

以下模式不自动形成 Finding：标准 defer 配对、正常错误透传、预分配、受锁保护的初始化、短生命周期 goroutine、无人依赖关闭信号的 channel、符合契约的阻塞 select、Go 1.22 以上标准循环变量、已触发的一次性 timer，以及框架或仓库 helper 已提供的恢复、鉴权、事务或资源管理。

纯命名、格式、注释、文件组织和个人偏好不形成 Finding。

每条 Finding 必须回答：

1. 当前 diff 的哪一行引入、暴露或扩大问题。
2. 什么输入、状态或执行顺序可以触发。
3. 附近代码、框架或仓库规范为何没有消除风险。
4. 用户或系统可观察的影响是什么。
5. 最小修复方向是什么。

无法回答时继续核验或降为审查缺口，不输出猜测性 Finding。
