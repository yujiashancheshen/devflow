# 数据、事务与消息

改动涉及数据库、缓存或 MQ 时应用本文件。

## SQL 与事务

- 外部值使用占位符；动态表名、列名和排序字段必须来自白名单。
- 检查查询条件、数据归属、影响行范围、分页、索引和并发写冲突。
- Begin 成功后的所有退出路径必须 Commit 或 Rollback，并处理 Commit 错误与事务 helper 的真实语义。
- 网络、MQ、文件等不可回滚副作用进入事务时，检查超时和失败恢复。

## 缓存与消息

- 检查 key、TTL、空值、序列化格式和读写顺序是否产生长期脏读。
- 分布式锁检查 owner token、超时、续期和只释放自己的锁，但不机械要求复杂方案。
- 消费者按设计处理非法消息、重复投递、乱序、重试和部分成功。
- ack 时机、幂等键、消息字段、版本和生产消费双方契约必须一致。

## 高风险状态

- 金额检查单位、舍入、符号、上下限、重复执行和不可变支付快照。
- 状态推进检查影响行数或 CAS 条件，避免并发重复推进和旧状态覆盖新状态。
